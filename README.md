# الموقع الشخصي للقارئ نور الدين المسلاتي

> English version: [README.en.md](README.en.md)

موقع ثابت (Static) للتلاوات القرآنية كاملة — **١١٤ سورة برواية قالون عن نافع** — مع مشغّل صوتي مستمر، ونص مصحفي متصل، وتتبّع الكلمة الجارية أثناء التلاوة. عربي (افتراضي) وإنجليزي.

- **الموقع:** https://noureddinealmselati.com.ly · النسخة الإنجليزية: `/en/`
- **المواصفات الكاملة:** `PRD.md`

## الميزات

- **١١٤ سورة** مع البحث الفوري بالاسم أو الرقم (يتجاهل التشكيل والهمزات)، وعرض مكية/مدنية وعدد الآيات ومدة التلاوة.
- **مشغّل صوتي ثابت** أسفل الشاشة: يستمر أثناء التنقل بين الصفحات، تشغيل/إيقاف، السابق/التالي، تقديم وتأخير ١٠ ثوانٍ، سرعة ٠٫٧٥×–٢×، انتقال تلقائي للسورة التالية، ودعم **Media Session** (شاشة القفل والإشعارات)، واستئناف آخر موضع من `localStorage`.
- **الموقع يتبع التلاوة**: عند تشغيل سورة من الرئيسية أو من قائمة السور تُفتح صفحتها تلقائيًا، وكذلك عند الانتقال إلى السورة التالية بعد انتهاء التلاوة — مع بقاء الصوت يعمل أثناء التنقل، وعدم مقاطعة تصفّح بقية الصفحات.
- **نص السورة برواية قالون** (٦٢١٤ آية) مضمَّن في HTML الثابت — يظهر بلا جافاسكربت، ومفهرس لمحركات البحث.
- **نمطان للعرض**: «قائمة» (آية في كل سطر مع وردة الرقم) و«مصحف» (نص متصل مضبوط `justify` مع فواصل الآيات `۝`).
- **نمط ثالث «مصحف (صفحات)»**: صفحات مصحف قالون بترقيم KFGQPC الحقيقي (٦٠٤ صفحة، ١٥ سطرًا في الصفحة) بخط المصحف، مع رقم الجزء واسم السورة في رأس الصفحة ورقم الصفحة في تذييلها، وتقليب تلقائي تتبعًا للتلاوة، وأزرار «السابقة/التالية»، وحفظ آخر صفحة لكل سورة (ولا يطمس التشغيل التلقائي موضع القارئ).
- **حجم المصحف في نمط الصفحات**: يتبع إعداد «حجم الخط» (١٠٠٪ / ١١٥٪ / ١٣٠٪) فيُكبَّر المصحف كله — نصّه وأسطره — دون أن يختلف عدد أسطر الصفحة (١٥ دائمًا)، وتُقاس المساحة المتاحة من الترويسة وشريط المشغّل فعليًا لا تقديرًا ثابتًا. وعلى الجوال يتجاوز المصحف عرض الشاشة فيُمرَّر أفقيًا.
- **وردة رقم الآية**: يرسمها خط KFGQPC وردة واحدة تحمل الرقم (كما في المصحف المطبوع) في الأنماط الثلاثة، بلا وردة فارغة إضافية.
- **تأثيران للقراءة**: «لون باهت» يتلوّن تدريجيًا مع التلاوة، أو «ظهور تدريجي» للكلمات المقروءة.
- **تتبّع الكلمة الجارية** بدقة الكلمة + تمرير تلقائي يبقي الآية فوق شريط المشغّل، والنقر على أي كلمة أو آية يبدأ التشغيل من موضعها.
- **إعدادات عرض** محفوظة: المظهر (فاتح/داكن/النظام)، حجم الخط، نمط العرض، وتأثير القراءة — تُطبَّق قبل الرسم بلا وميض.
- مشاركة وتحميل مباشر لكل سورة، وOpen Graph و`Schema.org` وخريطة موقع.

## البدء السريع

المتطلبات: **Node.js 22** (حسب `.nvmrc`) وPython 3 اختياريًا لأدوات التوقيتات.

```bash
npm ci          # تنصيب الاعتماديات
npm run dev     # خادم التطوير
npm run build   # تصدير ثابت إلى out/
npm run lint    # ESLint
npm run typecheck  # tsc --noEmit
```

> المشروع ثابت بالكامل: لا توجد Pages Functions ولا قاعدة بيانات ولا تحليلات من جهة الخادم. كل حالة المتصفح في `localStorage` فقط.

### متغيرات البيئة

| المتغير | الوصف |
|---|---|
| `NEXT_PUBLIC_AUDIO_BASE_URL` | الرابط الأساسي لملفات الصوت. في الإنتاج: `https://audio.noureddinealmselati.com.ly/audio`، وفي التطوير الافتراضي `/assets/audio`. |

`src/data/recitations.json` يحفظ **اسم الملف فقط** (`001.mp3`)، والرابط الكامل يُركَّب وقت التشغيل في `src/lib/data.ts` — أي يمكن نقل الصوت لمصدر آخر بتغيير متغير واحد.

## البيانات

| الملف | المحتوى | الحجم |
|---|---|---|
| `src/data/surahs.json` | ١١٤ سورة: الرقم، الاسم، المعنى، مكية/مدنية، عدد الآيات | صغير |
| `src/data/recitations.json` | ربط كل سورة بملف الصوت ومدته | صغير |
| `src/data/quran/qalun/NNN.json` | نص المصحف برواية قالون: `{a, hafs[], t}` لكل آية | ١٫٨ MB |
| `src/data/quran/timings/NNN.json` | توقيت كل آية: `{a, start, end, score}` | ٦٣٦ KB |
| `src/data/quran/timings/words-NNN.json` | توقيت كل كلمة `[[start,end],…]` بترتيب النص | ١٫٢ MB |
| `src/data/quran/layout/NNN.json` | بنية صفحات مصحف قالون: `{surah, bookPages, linesPerPage, from, to, pages[{p, j, items[]}]}` | ٥٦٤ KB |
| `src/data/quran/layout/source.json` | وصف المصدر وبصمة SHA-256 لملف KFGQPC المُحمَّل | صغير |

### تحديث البيانات

```bash
node scripts/build-surahs.mjs        # يبني surahs.json (جدول أسماء مرجعي ثابت)
node scripts/build-quran-text.mjs    # ينزّل نص قالون ويتحقق من بصمة SHA-256 ثم يكتب quran/qalun/
node scripts/build-qaloon-layout.mjs # ينزّل تخطيط صفحات KFGQPC ويتحقق من بصمته ثم يكتب quran/layout/
```

تخطيط الصفحات من ملف **KFGQPC Qaloon v10** (`quran-data-kfgqpc`) — يُثبَّت ببصمة SHA-256 داخل السكربت، ويتحقق البناء من أن كل سورة تُعاد تركيبها من كلماتها بلا نقص أو زيادة قبل الكتابة. عناصر كل صفحة: آية كاملة `{k:"a",i}` أو جزء آية يعبر بين صفحتين `{f,t}`، أو نص سورة مجاورة للسياق `{k:"x"}` (غير قابل للنقر)، أو رأس سورة `{k:"s"}` أو بسملة `{k:"b"}`.

نص المصحف من [iptvchecker/content-quran-json](https://github.com/iptvchecker/content-quran-json) (طبعة Quranpedia / KFGQPC) — **٦٢١٤ آية** برواية قالون مقابل ٦٢٣٦ في حفص، والاختلاف في ٥٠ سورة. لا يُستخدم `uthmani_qaloon` من quran.com لأنه بترقيم حفص.

**إضافة سورة صوتية جديدة** لا تحتاج أي تعديل في الكود: ضع الملف `NNN.mp3` في مجلد `audio/` داخل bucket الـ R2، وأضف سطرًا واحدًا في `recitations.json` (`{"surah": N, "file": "NNN.mp3", "duration": 0}` — والمدة بالثواني، و`0` تعني إخفاء المدة فقط).

## خط أنابيب التوقيتات

التوقيتات مستخرجة بمحاذاة قسرية لملف الصوت مع نص المصحف: تحويل الكلام إلى نص مع طوابع زمنية للكلمات (faster-whisper `large-v3`)، ثم محاذاة الحلقة الهرمية (Needleman–Wunsch) بين كلمات المصحف المعلومة والكلمات المُتعرَّف عليها. الحساب على **Kaggle GPU** لأن إعداد whisper محليًا ليس عمليًا.

```bash
# ١) تشغيل النواة على Kaggle (تعالج ١١٤ سورة في نحو ساعتين على T4)
cd tools/kaggle-timing
kaggle kernels push -p . --accelerator NvidiaTeslaT4 --timeout 28800
# ٢) تنزيل المخرجات: timings-*.json و qc-*.md و asr-words-*.json
kaggle kernels output <kaggle-user>/mselati-qaloon-timing -p /tmp/kaggle-out
# ٣) توليد توقيتات الكلمات محليًا من مخرجات ASR المحفوظة (بلا GPU، دقائق)
python3 tools/kaggle-timing/emit_word_timings.py /tmp/kaggle-out
```

ملفات `asr-words-NNN.json` هي المصدر الذي يبنى عليه `words-NNN.json` محليًا؛ لا تُعاد النواة لتعديل دقة الكلمات. تفاصيل الإعداد في `kernel-metadata.json` (GPU، إنترنت، نواة خاصة)، والنواة تحتاج رمز Kaggle في `~/.kaggle/` (خارج المستودع).

جودة التوقيت (مقيسة على كامل المصحف): ٩٩‏٫٢٪ من الآيات بتغطية كلمات طبيعية، ومتوسط ثقة المطابقة ٠٫٨٤، و٩٩‏٫٨٪ من الكلمات (من ٧٧٬٨٥٣) مرتبطة مباشرة بتوقيت ASR والباقي مُستوفى داخل مدى الآية.

## الصوت على R2

ملفات الصوت **لا تُرفع إلى Git أبدًا** (`*.mp3` و`audio-raw/` و`audio-final/` مستثناة في `.gitignore`)؛ تُستضاف على Cloudflare R2 وتُقدَّم عبر دومين فرعي، بترويسة `Cache-Control: public, max-age=31536000, immutable` ودعم طلبات النطاق (Range) للقفز داخل السورة.

## النشر

كل دفع إلى `main` يشغّل `.github/workflows/deploy.yml`: `npm ci` ← `npm run typecheck` ← `npm run build` ← رفع `out/` إلى Cloudflare Pages عبر `wrangler-action`. الأسرار المطلوبة: `CLOUDFLARE_API_TOKEN` و`CLOUDFLARE_ACCOUNT_ID`. الرابط الأساسي للصوت يُمرَّر كمتغير بيئة في سير العمل.

## الوصول والأداء

- النص يُصيَّر على الخادم دائمًا، والتتبّع اللحظي يعدّل أصناف CSS للكلمتين المتغيّرتين فقط عبر `requestAnimationFrame` (بلا إعادة رندر).
- احترام `prefers-reduced-motion`، وأزرار لمس ≥ ٤٨px، وإمكانية التشغيل بلوحة المفاتيح عبر وردة الآية.
- `preload="metadata"` فلا يُنزَّل الملف الصوتي قبل الضغط على التشغيل.
